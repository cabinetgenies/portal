# Assistant memory policy

Phase 7A retains private conversation history and completed run artifacts only.
Durable personalization is opt-in and may be deferred; there is no automatic
company-wide learning.

- Financial amounts, payment status, current roles and approvals are fetched from
  authoritative records, never recalled from memory.
- Employee and customer memories are not stored in Git and not stored in a single
  shared MEMORY.md.
- Runtime agents do not self-edit production instructions or self-install skills.
- If ownership or access changes, access to derived artifacts is revalidated
  before they are returned.
